### Employee lifecycle automation (issue #31)

- Role-change and department-transfer workflow templates, with `employee.role_changed` and `employee.transferred` events and start rules.
- The Microsoft and Google directory syncs now raise hire / departure / role-change / transfer events (only when "Start workflows automatically" is on).
- Onboarding form (questions asked when a workflow starts, usable as `{{var.name}}`) and conditional tasks (department, job title, employee type, form answer); the dry run shows what is left out.
- Delayed tasks ("archive the record 30 days after the end date"): scheduled status, run now / skip, released by `cron/workflow_cron.php`.
- New actions: assign / collect devices, archive the record, Microsoft 365 licences, mailbox automatic reply, Odoo create / archive (off by default, own setting), identity-system connectors (stubs).
- Bulk start for many people (email list / CSV, and from the People import); built-in presets and starter templates.
- Database 2.6.216 and 2.6.217.
- Unverified on real systems: Entra licence / mailbox actions, Odoo actions, identity connectors, directory-sync events (see docs/EMPLOYEE-LIFECYCLE-WORKFLOWS.md).
