# RivetIT Department Portal SSO for Odoo 19 and 20

This installable Odoo addon supplies the Odoo half of the browser-bound Department Portal sign-in flow. See [`docs/ODOO_PORTAL_SSO.md`](../../docs/ODOO_PORTAL_SSO.md) for installation, configuration, secret rotation and rollback. It has not been installed or exercised against a live Odoo instance in this checkout.
